# BioASQ 检索盲测

本目录用于测试 MedLit 当前的 Agent 检索流程。测试窗口只读取 `questions.json`，不得读取仓库中的 `evals/`、`data/`、benchmark、golden、答案或评分文件。

本轮只测试以下环节：

1. Agent 根据自然语言问题构造完整 PubMed query。
2. 通过插件执行 PubMed 搜索并阅读返回反馈。
3. 必要时重新构造 query，并比较前后结果。
4. 选择一个 query，记录最终检索结果。

不要执行全文下载、全文解析、证据抽取或答案生成。每题的过程状态和观察记录放在 `runs/` 下；记录 query、PubMed 返回数量、是否重试、最终 PMID 排名和问题，不记录或推测 gold PMID。

## 测试要求

- 按 `questions.json` 中的 `test_id` 逐题测试。
- 不要为了命中某篇预期论文而反向修改 query。
- 每次重试必须说明上一轮结果存在什么问题，以及本轮具体改动。
- 如果首轮结果已经足够，直接接受，不强制重试。
- 完成后只汇总检索过程指标，不生成答案质量结论。
