# MedLit 高召回与高命中升级计划

> **状态：已废止，不得据此实施。** 本稿含有已被否决的 MCP 和全面并行开发方案；请以 `medlit_retrieval_upgrade_review_v2.md` 为当前待审方案。

## 一、背景与总目标

当前系统已能完成 PubMed 检索、开放全文定位、规则抽取和报告生成，但生产插件与根目录源码不同步，查询扩展、排序、PDF 解析、并发调度和证据验证均较弱。本轮直接以 `plugins/medlit-cli` 为唯一实现源，目标是在保证可追溯、可恢复和合法获取全文的前提下，显著提升相关论文召回率、前列命中率及第三方安装可用性。所有优化先建立可复现基线，再以同一插件代码做消融和回归，避免评测结果与实际发布版本脱节。

## 二、评测口径

现有 `evals/score_bioasq.py` 将各次 `retrieval_runs` 的 PMID 按运行顺序合并去重，只计算 P@5/10/20、R@10/20、F1@10/20；官方评测另取前十篇计算 MAP，尚未正式定义“命中率”。本轮统一为：`Recall@K=|TopK∩Gold|/|Gold|`；单题 `Hit@K=1[TopK∩Gold≠∅]`，总体 Hit Rate 为全部问题的宏平均；Precision@K 固定以 K 为分母。新增 R@50/100、Hit@5/10/20、MAP@10、MRR、nDCG@20/50，并按题型报告均值和 bootstrap 95% 置信区间。以 BioASQ 13B 的 340 题为主基准，严格使用 `question_date` 截止文献日期，并建立缩写、罕见病、药物性质等困难子集。

## 三、六项架构决策

1. **插件规范性**：当前 manifest 和 Skill 虽通过校验，但个人 marketplace 指向错误、插件快照落后且第三方依赖流程不完整。删除双份运行时，以插件目录为源码和测试入口；升级为 Skill 与本地 MCP 混合插件，补齐许可证、锁定依赖、环境自检、隐私与安装说明、语义版本及 cachebuster。使用官方 validator、Skill validator、全新用户目录安装和新线程加载测试，先支持 Git 仓库 marketplace 安装，再准备公共插件目录发布。
2. **并行 Worker**：建设真正的受限并发调度器。以 SQLite WAL 保存任务、依赖、租约、心跳、重试、幂等键、优先级和产物；查询变体、PubMed 分批抓取、全文定位、解析及证据抽取可并行，失败任务独立降级。对 NCBI、Europe PMC 和 Unpaywall 分别设置并发信号量、令牌桶和退避策略，并支持取消、断点恢复与崩溃后续租。
3. **Orchestrator**：有必要，但应是本地确定性状态机而非另一个自由推理 Agent。它负责 DAG、预算、阶段门槛、任务合并、召回饱和判断、错误分类和审计；Codex只负责 PICO 审阅、歧义消解、查询建议及最终证据综合。这样既保留模型能力，也避免逐命令编排造成循环、状态漂移和不可复现。
4. **PICO、MeSH 与检索式**：先识别问题类型并选择 PICO、PECO、PCC 或 SPIDER，输出规范实体、同义词、缩写、否定项、时间范围和置信度。MeSH 层解析 preferred term、entry term、tree number、爆破与限定词，并保留 Title/Abstract 自由词。查询采用 recall-first 梯形策略：同概念 OR、核心概念 AND、过滤条件后置；并行执行宽检索、精确短语、MeSH 与自由词变体，使用 RRF 合并，再结合标题摘要语义、词项覆盖和发表日期重排。
5. **全文 PDF**：继续限定 PMC、Europe PMC、Unpaywall 等合法开放来源，下载时记录许可、URL、MIME、哈希和访问时间。使用 PyMuPDF 提取带页码、块坐标和章节信息的文本，扫描件在依赖可用时进入 OCR；设置文本长度、乱码率和章节覆盖质量分。解析失败才降级摘要，`pdf_placeholder` 不得进入证据、报告或验证通过路径。
6. **其他优化**：增加 Europe PMC 检索、相关文献与引用扩展、DOI/PMID/标题去重、HTTP 缓存 TTL、批量 EFetch、查询审计及可定位证据。引入轻量学习排序或可替换嵌入后端，但保证无模型时仍能用 BM25/RRF 运行；同时补充单元测试、契约测试、故障注入和困难样本回归。

## 四、实施阶段与验收

P0：统一插件源码、修复安装链并冻结基线；P1：重写评测指标、PICO/MeSH 和查询构建；P2：交付 orchestrator、SQLite 队列和并行 Worker；P3：完成 PDF/OCR、证据定位和强验证；P4：接入多源召回与重排，运行消融、340 题全量评测和全新环境安装测试。合并门槛为 Hit@10、Recall@20/50 相对基线提升至少 20%，MAP@10 不下降超过统计误差；插件校验、断点恢复、限速、PDF 质量和引用溯源测试全部通过。若召回提升以明显牺牲精度或运行成本为代价，按查询变体分别保留开关并记录取舍。
