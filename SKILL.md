# medlit-cli

This skill gives Codex a biomedical literature research toolbox. It is not a
hard-coded demo workflow. Codex should inspect the state, call the next useful
CLI command, and stop when `diagnose` says the run is complete, degraded-ready,
or blocked.

## Core Rule

Python tools execute bounded operations. Codex is the agent core and owns:

- choosing the next command,
- deciding when to retry,
- deciding when to degrade,
- deciding when to stop,
- explaining limitations to the user.

Use the shared state file as the source of truth.

```bash
python scripts/medlit_cli.py --state workspace/latest/state.json status
python scripts/medlit_cli.py --state workspace/latest/state.json diagnose
```

## Typical Command Loop

Start a run:

```bash
python scripts/medlit_cli.py --state workspace/latest/state.json init --question "QUESTION"
```

Then let `diagnose` guide the next command. Common commands:

```bash
python scripts/medlit_cli.py --state workspace/latest/state.json decompose
python scripts/medlit_cli.py --state workspace/latest/state.json plan-terms
python scripts/medlit_cli.py --state workspace/latest/state.json validate-mesh
python scripts/medlit_cli.py --state workspace/latest/state.json build-query
python scripts/medlit_cli.py --state workspace/latest/state.json search-pubmed --retmax 20
python scripts/medlit_cli.py --state workspace/latest/state.json fetch-records
python scripts/medlit_cli.py --state workspace/latest/state.json localize-fulltext
python scripts/medlit_cli.py --state workspace/latest/state.json parse-fulltext
python scripts/medlit_cli.py --state workspace/latest/state.json extract-evidence
python scripts/medlit_cli.py --state workspace/latest/state.json evolve
python scripts/medlit_cli.py --state workspace/latest/state.json report
python scripts/medlit_cli.py --state workspace/latest/state.json verify
python scripts/medlit_cli.py --state workspace/latest/state.json spawn-tasks
```

## Termination Discipline

Always run `diagnose` before another costly retry. Stop when:

- `termination_ready: true`, or
- `blocked: true`, or
- repeated infrastructure blockers appear in `hard_blockers`.

Do not loop on problems Codex cannot fix, such as network being unavailable,
missing required configuration, exhausted PubMed query budget, or missing local
PDF parser dependency. Report the blocker and the honest partial result.

Read [references/termination_policy.md](references/termination_policy.md) before
changing stop/degrade behavior.

## Full Text Policy

The tool only localizes open-access full text or user-provided local files. It
does not bypass paywalls. If full text cannot be found, it degrades to
`abstract_only` and records every attempted source in `fulltexts[]`.

Read [references/fulltext_download_policy.md](references/fulltext_download_policy.md)
before modifying full-text retrieval.

## Output Contract

The machine-readable source of truth is `research_state.json`; the schema lives
at [assets/research_state.schema.json](assets/research_state.schema.json).

Human-readable output is `report.md`, generated by `report`.

## When Not To Use

- Do not use for direct medical advice.
- Do not use to fetch paywalled papers.
- Do not use local heuristic PICO decomposition; PICO must come from Codex or an explicit user/agent-provided JSON file.
- Do not cite evidence that is not traceable to a PMID/DOI/local source in state.
